# 本地旅行主理人 · 小红书账号运营工作台

纯静态站点（React 18 + htm + Ant Design v4 UMD，无构建步骤）。

## 本地预览

```bash
python3 -m http.server 3030
# 打开 http://localhost:3030/
```

## 结构

- `index.html` / `app.js` / `theme.css` — 主站
- `index-classic.html` / `app-classic.js` / `style.css` — 经典版
- `vendor/` — React / antd 等依赖（UMD 本地化）
- `assets/` — 图片资源

由 redcowork AI 建站助手搭建。
